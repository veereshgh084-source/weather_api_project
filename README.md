# weather_api_project
a python project using HTTP API JSON
Weather API Project 🌦️

About

This is a Python project that fetches real-time weather information using an HTTP API.

Technologies Used

* Python
* HTTP Requests
* JSON
* Weather API

Features

* Fetches weather data from an API.
* Retrieves latitude and longitude.
* Processes JSON responses.
* Displays weather information.

Learning Outcome

Learned how to work with APIs, HTTP requests, and JSON in Python.
